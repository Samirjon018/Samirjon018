## 🚀 Loyiha Haqida
**Tandir Restaurant** — bu zamonaviy va yuqori tezlikda ishlaydigan restoran veb-ilovasi bo'lib, foydalanuvchilarga restoranning taomlar menyusi bilan tanishish, onlayn buyurtma berish va xizmatlardan qulay foydalanish imkoniyatini beradi. Loyiha so'nggi zamonaviy veb-texnologiyalar yordamida noldan ishlab chiqilgan.

🔗 **Jonli sayt:** [tandir-restaurant.vercel.app](https://tandir-restaurant.vercel.app/)

---

## 🛠️ Ishlatilgan Texnologiyalar (Tech Stack)

* **Frontend:** Next.js, React, Tailwind CSS
* **Backend & Database:** Supabase (`@supabase/supabase-js`)
* **Integratsiya:** Telegram Bot API (buyurtmalarni avtomatlashtirilgan tarzda real vaqt rejimida qabul qilish)
* **Deploy:** Vercel

---

## ✨ Asosiy Xususiyatlar

* 📱 **To'liq Responsiv Dizayn:** Barcha turdagi qurilmalarda (mobil telefon, planshet, kompyuter) mukammal ko'rinish.
* ⚡ **Tezkor Ishlash:** Next.js server komponentlari yordamida sahifalarning yuqori tezlikda yuklanishi.
* 🗄️ **Ma'lumotlar Bazasi:** Supabase orqali ma'lumotlarni xavfsiz boshqarish.
* 🤖 **Telegram Avtomatlashuvi:** Kelib tushgan buyurtmalar to'g'ridan-to'g'ri restoran menejerining Telegram botiga yuboriladi.
